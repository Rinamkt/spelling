# Spelling Bee · En familia

Piloto para practicar 110 palabras con acompañamiento familiar. HTML, CSS y JavaScript estáticos, sin instalación ni claves API.

Incluye perfiles locales, instrucciones en español con voces seleccionables, dictado con correcciones, completar letras, práctica oral revisada por un adulto, repasos y copias de avance.

## Vercel

Importar Rinamkt/spelling. Directorio raíz: raíz del repositorio. Framework: Other. Sin comando de compilación. La configuración vercel.json publica los archivos de la raíz.

## Datos y cambio de dominio

El avance se guarda en este navegador y dominio. Antes de cambiar de dominio, descargar una copia desde Para papás e importarla en el sitio nuevo. No hay sincronización automática ni cuentas con contraseña. No subir las copias de avance al repositorio.

## Prueba familiar

Crear un apodo, escuchar instrucciones, completar una ronda, comprobar una respuesta incorrecta, probar el regreso desde Cómo se juega y revisar el modo oral con un adulto. Verificar audio, teclado y botones en celular y tablet.
